# 奇幻冒险RPG - Fantasy RPG Adventure

一个开放式的安卓角色扮演小游戏，包含魔法系统、怪物战斗、地图探索和程序化音乐！

## 游戏特色

### 核心玩法
- **开放式世界探索** - 自由探索包含多种地形的大世界地图
- **回合制战斗** - 策略性的回合制战斗系统，包含元素克制机制
- **魔法系统** - 6种独特的魔法技能（火球术、冰霜新星、雷电术、治愈之光、火焰风暴、神圣护盾）
- **角色成长** - 升级系统，学习新技能，提升属性
- **物品系统** - 药水、装备、宝箱收集

### 怪物种类
1. **史莱姆** - 新手怪物，弱小但数量多
2. **哥布林** - 会使用快速突刺的狡猾敌人
3. **骷髅战士** - 亡灵生物，防御较高
4. **暗黑骑士** - 强大的黑暗系敌人
5. **兽人勇士** - 力量型敌人，攻击力高
6. **炎龙** - 火属性BOSS级怪物
7. **冰霜巨龙** - 冰属性最强BOSS

### 元素克制系统
- 🔥 火克冰 ❄️
- ❄️ 冰克火 🔥
- ⚡ 雷电克水/冰 💧
- ✨ 圣光克暗黑 🌑

### 音乐音效（程序化生成）
- 🎵 城镇背景音乐 - 轻松愉快的旋律
- 🎵 战斗背景音乐 - 激昂紧张的节奏
- 🎵 野外探索BGM - 宁静自然的氛围
- 🔊 攻击/受击/魔法/胜利/升级音效

## 操作方式

### PC端
- **WASD / 方向键**: 移动角色
- **空格键 / 回车**: 与NPC对话、打开宝箱
- **数字键 1-4**: 战斗中快捷操作（攻击/魔法/物品/逃跑）
- **ESC / 返回键**: 返回上级菜单
- **鼠标/触摸**: 点击按钮、虚拟摇杆移动

### 安卓端
- **虚拟摇杆**: 触摸并拖动来移动
- **点击按钮**: 执行各种操作

## 安装与运行

### 方式一：直接运行Python版本

```bash
# 安装依赖
pip install kivy numpy

# 运行游戏
python fantasy_rpg_complete.py
```

### 方式二：打包为安卓APK

```bash
# 安装buildozer
pip install buildozer

# 初始化buildozer（首次）
buildozer init

# 打包APK（debug版本）
buildozer android debug

# 或打包release版本
buildozer android release
```

生成的APK文件在 `bin/` 目录下。

## 项目结构

```
fantasy_rpg/
├── fantasy_rpg_complete.py   # 完整游戏代码（主文件）
├── fantasy_rpg.py            # 基础版游戏代码
├── music_generator.py        # 音频资源生成器
├── buildozer.spec            # 安卓打包配置
└── assets/
    └── audio/                # 生成的音频文件目录
        ├── bgm_town.wav      # 城镇BGM
        ├── bgm_battle.wav    # 战斗BGM
        ├── bgm_field.wav     # 野外BGM
        ├── sfx_attack.wav    # 攻击音效
        ├── sfx_magic.wav     # 魔法音效
        ├── sfx_hit.wav       # 受击音效
        ├── sfx_victory.wav   # 胜利音效
        └── sfx_levelup.wav   # 升级音效
```

## 技术栈

- **Kivy** - Python跨平台GUI框架
- **NumPy** - 数值计算（音频合成）
- **Buildozer** - Python到安卓的打包工具
- **程序化音频** - 使用数学函数合成音乐和音效，无需外部音频文件
